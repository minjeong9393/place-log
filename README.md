# SCMJ 장소

부부가 같이 **가볼 곳**을 지도에 담고, 다녀온 곳은 **별점·후기**로 남기는 웹앱(PWA)입니다.
광고·추적·외부 SDK 없이 화면 하나(`index.html`)로 동작하고, 담은 곳은 기기 브라우저(`localStorage`)에
저장됩니다. 남편과 연동하면 방 코드를 아는 기기끼리 실시간으로 같은 지도를 봅니다.

- 앱 이름: **SCMJ 장소** (저장소는 `place-log` 또는 `scmj-places`)
- 앱 주소: 배포 후 `https://minjeong9393.github.io/<저장소>/` — 폰 크롬에서 열고 `홈 화면에 추가`를 누르면 앱처럼 열려요
- 색: 청록 `#0f7a6c` · 가보기 전 핀 주황 `#e2603a` · 가본 곳 핀 청록 `#0f7a6c` · 배경 `#f6f7f6`
- 저장: `localStorage['place_log_state_v1']` (장소 목록) · `place_log_prefs_v1`(필터) · `place_log_origin_v1`(거리 기준점) · `place_log_room_v1`(연동 방)
- 아이콘: 보내 준 헬로키티 사진을 정사각형 풀블리드로 잘라 `favicon.ico`·`icon-192.png`·`icon-512.png`·`apple-touch-icon.png` 로 씀

## 화면

| 화면 | 내용 |
| --- | --- |
| **목록** | 위에 상태 탭(전체/가보기 전/가본 곳 · 개수)과 카테고리 칩, `총 N곳 · 평균 별점 · 거리 기준`. 카드에는 카테고리 아이콘, 장소명, 상태 배지, **직선 거리**, 주소, 메모·후기, 별점·방문일·추천 메뉴 |
| **지도** | Leaflet + OpenStreetMap. **가보기 전 = 주황 핀**, **가본 곳 = 청록 핀**, 핀 안에 카테고리 아이콘. 핀을 누르면 장소 정보·후기·`상세`·`네이버`·`카카오` 버튼이 뜨고, `상세`는 그 자리에서 수정 |
| 폰 | 아래 탭 `목록 / 지도`, 오른쪽 아래 `＋` |
| PC | 왼쪽 목록 + 오른쪽 지도 두 단, 위쪽 `＋ 추가` |

- 위쪽 검색창에서 장소명·주소·메모·후기·추천 메뉴 검색, `거리순`·`최근 담은순`·`별점순`·`이름순` 정렬.
- 목록은 `가보기 전` / `가본 곳` 으로 묶여서 나오고, 정렬은 각 묶음 안에서 적용됩니다.

## 거리

- 내 위치(Geolocation)를 기준으로 각 장소까지의 **직선 거리**를 자동 계산합니다(1km 미만은 `m`, 그 이상은 `km`).
- 위치 권한을 거부하면 **대구 달서구 진천동**이 기본 기준점입니다.
- 지도 오른쪽 위 `📍 내 위치` 로 언제든 다시 잡을 수 있고, `🎯 기준점` 을 누르면 지도를 눌러 기준점을 직접 정합니다(`더보기 → 거리 기준점` 에서도 가능).

## 가까운 지하철역 (v1.1.0)

- 장소마다 **가장 가까운 지하철역과 거리**를 자동으로 계산해 카드·지도 팝업·상세에 보여 줍니다(예: `🚇 진천역 320m`, 상세는 `진천역 · 도보 약 4분 (320m)`).
- 전국 **1,317개 역 좌표**를 `stations.js` 에 내장해 API·네트워크 없이 계산합니다(대구 1·2·3호선과 대경선, 수도권 1~9호선·신분당·수인분당·경의중앙·공항철도·경춘·경강, 부산·김해, 대전, 광주, 그리고 일반 철도역까지). 좌표 출처는 OpenStreetMap(ODbL)과 Wikidata(CC0).
- 카드에는 **3km 이내**만 배지로 나오고, 상세·팝업은 5km 까지 보여 줍니다. 0~2km 는 도보 시간(분)도 함께 계산합니다.
- 검색창에 역 이름을 넣으면(`진천역`) 그 역에서 **걸어갈 만한 1.2km 안** 장소도 함께 찾아 줍니다.
- 엑셀(.xlsx) `가볼곳` 시트에 `가까운 역` 열이 추가됩니다.
- 역 좌표를 새로 만들려면: `python3 tools/build_stations.py` (Overpass·Wikidata 수집본 `tools/stations/*.json` 사용) → `site/stations.js` 재생성.

## 담기

1. `＋`(PC 는 `＋ 추가`) → 장소명(필수), 카테고리(식당·카페·나들이/전시·여행/숙소·기타), 상태.
2. 위치는 세 가지 —
   - **📮 주소 찾기** — 카카오(다음) 우편번호 서비스를 앱 안 레이어로 띄워 **도로명·지번 주소·건물명**으로 찾습니다. 고르면 `대구 달서구 진천로16길 26` 같은 한국식 도로명 주소가 그대로 들어가고, 좌표와 가까운 지하철역까지 자동으로 채워집니다(모바일 팝업 차단 없음).
   - **🔎 이름·주소로 검색** — 상호명·역 이름으로 찾을 때(OpenStreetMap Nominatim, 국내 우선·한국어). 결과는 `장소명 / 시·도 구·군 도로명 번지` 로 한국식 순서로 보여 줍니다.
   - `🗺 지도에서 찍기` → 지도를 한 번 누르면 그 좌표가 들어가고 주소는 자동으로 채워집니다(비어 있을 때만).
3. `가본 곳` 으로 바꾸면 **방문일(기본 오늘) · 별점(0.5점 단위) · 짧은 후기** 칸이 열립니다.
4. 추천 메뉴·메모도 남길 수 있고, `네이버지도 열기` / `카카오맵 열기` 로 바로 길을 찾을 수 있습니다.

## 주소 표시 (v1.2.0)

- 주소는 언제나 **한국식 순서**입니다 — `시/도 + 시·군·구 + 도로명 + 번지`(도로명이 없으면 `동`). Nominatim 이 주는 `진천로16길, 진천동, 달서구, 대구광역시, 42784, 대한민국` 같은 역순·영문 표기를 그대로 쓰지 않고 앱에서 다시 만듭니다.
- 주소 찾기(카카오 우편번호)는 `t1.kakaocdn.net` 에서 스크립트를 받고, 실패하면 `t1.daumcdn.net`(2026-11-30 종료 예정)으로 한 번 더 시도합니다. 둘 다 안 되면 “주소를 직접 입력하고 지도에서 찍어 달라”고 안내합니다.
- 좌표는 Nominatim 지오코딩으로 찾습니다. 번지까지 못 찾으면 도로명만으로 한 번 더 찾고, 그래도 없으면 주소만 넣고 지도 찍기를 권합니다.
- 주소만 있고 좌표가 없는 장소는 지도에 핀을 찍지 않습니다(예전에 `0,0` 에 핀이 찍히던 문제 수정).

## 남편 연동 (부부 공유)

`⋮ → 남편 연동` 또는 위쪽 `☁️ 혼자` 칩:

1. `새 방 만들기` → `place-xxxxxx` 코드가 만들어지고 이 기기의 목록이 올라갑니다.
2. `초대 링크 복사` → 카톡으로 보내면 남편은 링크(`#room=...`)만 누르면 연결됩니다.
3. 다른 기기에서는 `방 코드로 참여` 에 코드를 넣어도 됩니다.

- 장소 하나를 저장하면 `/rooms/{방}/places/{id}` 한 군데만 PUT 합니다(다른 장소는 안 건드림).
- 삭제는 그 경로 DELETE + `/removed/{id}` 에 삭제 표시 — 다른 기기의 옛 사본이 되살리지 않습니다.
- `EventSource` 로 방 전체를 구독해 남편 폰의 추가·수정·삭제가 바로 반영됩니다.
- 연동을 해제해도 기록은 이 기기에 남습니다.

## 백업

- `더보기 → 엑셀(.xlsx) 내보내기` — 지금 목록 기준, 2장(`가볼곳` · `카테고리 요약`). 별점은 `#,##0.0`, 거리는 `m` 숫자.
- `더보기 → JSON 백업 내보내기` / `백업 불러오기` — 백업 파일은 `합치기` 또는 `덮어쓰기` 로 복원.
- `전체 초기화` 는 이 기기 목록만 지웁니다(연동 중이면 방에도 반영).

## 아이콘 바꾸기

`tools/make_photo_icons.py` 로 사진 한 장이면 아이콘 4종이 다시 만들어집니다.

```
python3 tools/make_photo_icons.py 사진.jpg            # 정사각형 가운데 크롭
python3 tools/make_photo_icons.py 사진.jpg --zoom 1.2 # 조금 확대해서 크롭
```

기본 지도 핀 아이콘을 쓰고 싶으면 `tools/make_icons.py`.
사진·아이콘을 바꾼 뒤에는 `sw.js` 의 `CACHE = 'place-log-v3'` 버전을 올리고,
안드로이드 홈 화면 앱은 **설치 삭제 후 다시 추가**해야 새 아이콘이 적용됩니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체(화면·스타일·동작·엑셀 생성기) — 외부 SDK 없음 |
| `stations.js` | 가까운 지하철역 좌표 테이블(전국 1,317역 · `[이름, 위도, 경도, 도시철도여부]`) |

| `sw.js` | 서비스워커 `place-log-v3` — 화면·매니페스트는 네트워크 우선, Leaflet 은 캐시, 지도 타일은 통과 |
| `icon-192.png` `icon-512.png` `apple-touch-icon.png` `favicon.ico` | 사진 아이콘 |
| `favicon.svg` | 지도 핀 SVG(사진 아이콘 대신 쓸 수 있는 예비본 — 지금은 연결하지 않음) |

## 참고

- 지도 타일은 OpenStreetMap, 주소 검색·좌표 찾기는 Nominatim(한국어·국내 우선), 도로명 주소 찾기는 카카오(다음) 우편번호 서비스를 씁니다(인터넷 필요). 지도가 안 뜨면 목록·저장은 그대로 쓸 수 있어요.
- 이 저장소는 공개되므로 **실제 장소·방 코드는 코드에 넣지 않았습니다**(`SEED = []`).
